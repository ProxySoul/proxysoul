Most coding agents read your codebase the way `grep` does — as strings. I kept asking: *why doesn't the agent get actual code intelligence?* So I built it.

- **[SoulForge](https://github.com/proxysoul/soulforge)** (v2) — the experiment. An AI coding agent with a code graph instead of grep. **840+ ⭐** and a community that proved the idea works.
- **[Empryo](https://empryo.com)** (v3) — the real thing, rebuilt from the ground up. AST surgery instead of string edits, full LSP, a live code **genome** of your repo — across a TUI, a desktop app, and headless CI. Faster, cheaper, and built on a solid layered architecture.

Free & BYOK · 22 providers (local models included) · 33 languages · one genome, three bodies: desktop, TUI, headless CI.
